# Roteiro de desenvolvimento

## Etapa 1 — Fatia vertical (ESTA ENTREGA)
- [x] Base FPS: movimento, corrida, agachar, pulo, colisão, câmera, ADS, recuo
- [x] Armas fictícias VK-7 e P-11, recarga, troca, granadas, munição
- [x] Vida com regeneração, indicadores de dano, morte e reinício
- [x] IA aliada (esquadrão, cobertura, avanço) e inimiga (cobertura, espiar, atirador, RPG, metralhadora)
- [x] Missão 1: abertura no helicóptero, pouso, emboscada, 3 ondas de combate, Edifício Halden
- [x] Checkpoints e salvamento, menu, pausa, configurações, qualidade gráfica
- [x] Chuva, fumaça, fogo, explosões, poeira do rotor, decalques

## Etapa 2 — Missão 1 completa (FEITO)
- [x] Arrombamento da porta e interior do Edifício Halden (saguão, corredor, sala dos servidores)
- [x] Download dos servidores sob contra-ataque do VÉRTICE
- [x] Reviravolta: os códigos são do próprio Comando da Coalizão; contato com Bastião perdido
- [ ] Substituição dos primeiros recursos provisórios por arte definitiva

## Etapa 3 — Missão 2 "Sinal Morto" (FEITO)
- [x] Sistema de várias missões: seleção no menu, progresso desbloqueado, "Próxima missão"
- [x] Iluminação de entardecer (sol baixo, neblina, chuva mais forte)
- [x] Nova área: rua transversal leste e complexo da estação de TV (muro, portão, torre de vigia, mastro de transmissão, contêineres)
- [x] Patrulha, bloqueio, assalto ao complexo e defesa do transmissor; segunda reviravolta (voz desconhecida)

## Etapa 4 — Missão 3 "Porto de Vareny" + otimização (FEITO)
- [x] Novo mapa: porto com pátio de contêineres, guindastes, galpão, mar e cargueiro com prancha
- [x] Abordagem, combate no convés, revelação (General Aldo Serrat) e fuga cronometrada
- [x] Regiões com navegação própria; grades de navegação para pisos elevados (convés)
- [x] Otimização: pool de 7 luzes, decalques instanciados, cidade em blocos com culling,
      sombras a cada 2 quadros, HUD sem reescritas desnecessárias, menos alocações
- [x] Vozes neurais/naturais com gênero certo por personagem; dificuldade um pouco maior
